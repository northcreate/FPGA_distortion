# 第三方依赖与授权说明（THIRD_PARTY）

本文档用于说明项目在 PDS 2025.2 环境下可能需要的第三方软件、FPGA IP 和 Python 依赖。**它不是厂商授权书，也不对第三方文件重新授予许可证。**

| 依赖 | 作用 | 使用与提交注意事项 |
| --- | --- | --- |
| Pango Design Suite（PDS）2025.2 | FPGA 综合、布局布线、时序分析及位流生成 | 需按紫光同创的官方许可安装使用；工具安装包不包含在仓库中。 |
| 官方 DDR3 IP / 相关 PHY 模块 | DDR3 控制与接口实现 | 工程使用适配 PDS 2025.2 的官方 IP。实际 IP 安装包、加密模型和生成 RTL 的可再分发权限应核对官方授权。 |
| 其他厂商生成 IP（如工程中实际存在的 PLL/RAM 等） | 时钟或存储功能 | 仅在许可允许时提交；重建工程时确保生成配置、版本和器件匹配。 |
| Python Tkinter | PC 控制界面 | 通常随 Windows Python 安装提供；遵守 Python/Tcl/Tk 的适用许可。 |
| PySerial | 串口通信 | 使用 `requirements.txt` 安装；遵守上游许可证。 |

## 本地重建建议

1. 安装相应授权的 PDS 2025.2 和 PGL50H 器件支持。
2. 按官方文档安装兼容的 DDR3 IP，并核对 IP 版本、器件与工程引用。
3. 打开 `Fpga_Project/HDMI_DDR3_OV5640_test.pds`，检查 `source/` 内的设计文件及全部 IP 依赖。
4. 完成综合、布局布线、时序检查；条件允许时再执行上板测试。

## 提交仓库前的授权检查

- 在公开仓库中提交加密 `.vp`、第三方 RTL、厂商生成模型等文件之前，应确认许可证是否允许再分发。
- 不应为了让工程“看起来完整”而上传不具备发布权限的厂商安装包。
- 如果某些依赖无法再分发，建议保留自己的顶层代码及合法可分享的配置，在 README 中明确描述依赖名称、所需版本和官方获取途径。
- 本项目并未自动将外部 IP 置于作者的许可范围之内。
