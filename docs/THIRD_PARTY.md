# 第三方依赖与开源合规声明 (THIRD_PARTY)

> 本工程遵循规范的开源与商业软件合规原则。本文档旨在清晰界定本项目在 PDS 2025.2 环境下所依赖的第三方组件、IP 模块与 Python 库，以保障工程的可复现性与版权合规性。

## 01 · 核心依赖矩阵

| 依赖组件 | 在本工程中的作用 | 授权与分发合规说明 |
| :--- | :--- | :--- |
| **Pango Design Suite (PDS) 2025.2** | FPGA 综合、布局布线、时序分析与比特流生成 | 遵循紫光同创官方商业许可。本工程不附带该工具的安装包，需在官方环境安装使用。 |
| **官方 DDR3 IP / PHY 模块** | DDR3 控制与高速接口实现 | 工程调用适配 PDS 2025.2 的官方 IP。其底层加密模型（如 `.vp` 文件）的版权归厂商所有，受原厂授权限制。 |
| **厂商生成 IP (如 PLL / RAM)** | 时钟与片上存储资源生成 | 仅在符合厂商许可的前提下随工程提供配置参数（`.ipc` 等）。重建时需确保生成版本与器件匹配。 |
| **Python Tkinter** | PC 端图形化上位机界面开发 | 通常随 Windows 标准 Python 环境提供，遵循 Python 软件基金会 (PSF) 许可。 |
| **PySerial** | PC 端串口通信协议栈 | 遵循 BSD 开源许可。可通过 `requirements.txt` 一键安装。 |

## 02 · 本地工程重建指南

为了在您的本地环境中合规、完整地重建本 FPGA 工程，请遵循以下标准流程：

1. **环境准备**：安装正版授权的 **PDS 2025.2** 及对应的 PGL50H 器件支持库。
2. **IP 核生成**：根据官方文档，在您的本地 PDS 环境中生成适配的 DDR3 IP，并检查版本匹配性。
3. **工程加载**：打开 `Fpga_Project/HDMI_DDR3_OV5640_test.pds`，检查 `source/` 目录下的 RTL 源码及所有 IP 引用路径。
4. **编译与验证**：依次执行综合、布局布线与时序检查。在确认时序收敛（All Constraints Met）后，执行上板验证。

## 03 · 仓库分发与版权声明

作为一个规范的开源硬件工程项目，我们在提交至 GitHub 时严格遵守以下原则：

- **纯净源码**：仓库仅包含作者自有的 RTL 源码、Python 上位机代码及合规的配置文件。已主动剔除所有体积庞大的综合缓存与工具日志。
- **尊重原厂版权**：不在公开仓库中直接分发未经授权允许再分发的厂商加密文件（如 `.vp`）、底层 RTL 或工具安装包。
- **依赖声明替代直接分发**：若某项厂商依赖无法直接开源，我们在上表中详细列出了其获取途径与版本要求，确保工程的可复现性。
