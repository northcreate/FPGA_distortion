# PGL50H / OV5640 图形化串口控制台

专用于 2026 FPGA 赛题二演示；Windows + Python 3.9+ + `pyserial`。Tkinter 随 Windows Python 通常一同安装。

## 快速启动

1. 电脑通过开发板板载 CP2102 USB 串口连接 FPGA；只允许一个程序占用对应 COM 端口。
2. 解压本压缩包；Windows 双击 **`run_windows.bat`**（会检查并安装 `pyserial`）。
3. 选择识别出的 COM 口，点击 **打开串口**；配置固定 **115200, 8N1**。
4. 勾选缩略图模式，输入角度如 `90`，点击 **发送配置**。可先使用预设按钮。
5. 使用 **快捷指令** 按钮控制 OSD、参考线和复位全屏。
6. 在参数区输入 Q16.16 *整数*，点击 **加载全部系数**（24 字节）。

命令行也可用：

```bat
python -m pip install -r requirements.txt
python app.py
python -m unittest -v test_protocol
```

## 从现有 `video_cmd_ctrl.v` 核实的协议

**主配置包：12 字节**

| 索引 | 含义 | 格式 |
| --- | --- | --- |
| 0,1 | 包头 | `A5 5A` |
| 2 | 类型 | `10` |
| 3 | flags | bit0 缩略图、bit1 畸变矫正、bit2 Gamma；高 5 位必须为 0 |
| 4,5 | 角度 | 无符号 16 位小端，0～359 |
| 6,7 | X 平移 | 有符号 16 位小端，-960～960 |
| 8,9 | Y 平移 | 有符号 16 位小端，-540～540 |
| 10 | XOR | **对索引 2～9 共 8 个字节进行 XOR** |
| 11 | 结束 | `0D` |

注意当前固件硬约束：`缩略图 OFF` 时 **角度必须是 0 且 Y 必须是 0**；X 平移允许。否则 FPGA 会拒绝该配置。

**已验证的示例：** `A5 5A 10 07 5A 00 00 00 00 00 4D 0D`（缩略图+畸变+Gamma，90°，X=Y=0）。

**全部四系数包：24 字节**

`A5 5A 12 00 [K1_LE32] [K2_LE32] [P1_LE32] [P2_LE32] 00 00 [XOR] 0D`

XOR 覆盖 **索引 2～21 共 20 字节**（不能沿用 12 字节包的 8 字节 XOR 范围）。四个系数都是 Q16.16 的**有符号32位整数**。如 K1=0.01 使用整数 **655** / `0x0000028F`；-1 可写 `-1` 或 `0xFFFFFFFF`。未加 `0x` 的纯数字按**十进制**解释。

硬件 `distortion_coeff_guard.v` 中的静态保护规则：

- `abs(K1), abs(K2) <= 2621`；`abs(P1), abs(P2) <= 262`。
- `6·abs(K1) + 4·abs(K2) + 24·abs(P1) + 14·abs(P2) <= 15726`。

软件对这些限制执行相同的预检；FPGA 仍会独立进行硬件检查。系数有效不代表几何精度已经实测达到某个阈值。

## 快捷指令

| 字节 | FPGA 功能 |
| --- | --- |
| `01` | 翻转畸变矫正开关 |
| `04` | 退出缩略图、角度/平移清零（不一定重置畸变或 Gamma） |
| `05` | 翻转 Gamma 开关 |
| `06` | 翻转白色辅助线开关 |
| `07` | 循环切换辅助线：十字线 / 边框 / 100px 网格 |
| `08` | 翻转透明 OSD 显示开关 |

**注意：单字节指令是翻转而不是设置到某个固定状态。** GUI 中的复选框仅记录本地希望发送的配置，并不是板端状态回读。若其他软件、板上按键或重新上电改变了状态，GUI 可能与真实状态不同，建议用完整 12 字节配置重新设定。

**无 ACK**：当前核对的 RTL 只接收命令并内部置位 `command_seen` / `command_error`，没有板端串口回复帧。软件“发送成功”只表示 PC 已写出串口数据；需结合 HDMI / OSD 验证生效，不能据此认为 FPGA 已接受命令。

## 适配说明
此软件只用于控制与参数生成，不会接收/显示 HDMI 视频，也不会修改 FPGA 的 32 拍流水线或 PDS 时序。
